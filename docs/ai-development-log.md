## 人工检查建议

提交前应人工确认：

1. 账户所选模型确实支持工具调用。
2. `.env`、数据库和 Trace 未被提交。
3. Mock 搜索与天气在录屏中被明确说明。
4. README 命令能在新环境中从零运行。
5. 真实 LLM 的三条验收对话至少手动执行一次。
